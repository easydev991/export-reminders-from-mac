## Why

Сейчас процесс сборки, подписи и запуска экспорта напоминаний требует ручного выполнения 3-4 команд из README. Нет единой точки входа для быстрого экспорта, а проверка инструментов разработки (swiftformat, periphery) описана только в AGENTS.md в виде напоминания. Makefile автоматизирует оба сценария: экспорт и настройку окружения.

## What Changes

- Добавить `Makefile` в корень проекта с двумя целями:
  - `make export` — сборка, подпись и запуск экспорта напоминаний за одну команду
  - `make setup` — проверка наличия Homebrew, swiftformat, periphery с диалоговой установкой отсутствующих компонентов
- Обновить `README.md` — добавить секцию быстрого старта через Makefile
- Не затрагивать основной Swift-код проекта

## Capabilities

### New Capabilities
- `makefile`: Автоматизация сборки, подписи и запуска экспорта, а также проверка и установка инструментов разработки

### Modified Capabilities
- *(нет изменений требований к существующим спекам — только новый Makefile)*

## Impact

- Корень проекта: новый файл `Makefile`
- `README.md`: добавить секцию с `make export` / `make setup`
- Основной код не затрагивается
