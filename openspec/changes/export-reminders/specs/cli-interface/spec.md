## ADDED Requirements

### Requirement: CLI точка входа
Приложение SHALL использовать `@main` entry point с `ParsableCommand`. Имя команды SHALL быть `export-reminders`.

#### Scenario: Запуск без аргументов
- **WHEN** команда вызывается без аргументов
- **THEN** используется формат `json` и файл `./reminders_export.json`

### Requirement: Аргумент --format
Аргумент `--format` SHALL принимать одно из двух значений: `json`, `csv`. Значение по умолчанию SHALL быть `json`. SHALL быть определён enum `Format: String, ExpressibleByArgument` со значениями `json`, `csv`.

#### Scenario: Указан формат json
- **WHEN** команда вызвана с `--format json`
- **THEN** используется `JSONExporter`

#### Scenario: Указан формат csv
- **WHEN** команда вызвана с `--format csv`
- **THEN** используется `CSVExporter`

#### Scenario: Неверный формат
- **WHEN** команда вызвана с `--format xml`
- **THEN** выводится сообщение об ошибке и `--help`

### Requirement: Аргумент --output
Аргумент `--output` SHALL принимать путь к выходному файлу. Значение по умолчанию SHALL быть `./reminders_export.json`.

#### Scenario: Указан свой путь
- **WHEN** команда вызвана с `--output ./out/backup.csv`
- **THEN** файл создаётся по пути `./out/backup.csv`

#### Scenario: Дефолтный путь
- **WHEN** команда вызвана без `--output`
- **THEN** файл создаётся как `./reminders_export.json`

### Requirement: Аргумент --list (фильтр по имени списка)
Аргумент `--list` SHALL принимать одно или несколько имён списков. При указании SHALL экспортироваться только напоминания из этих списков. Сравнение SHALL быть регистро-независимым. По умолчанию SHALL быть пустым (все списки).

#### Scenario: Фильтр по одному списку
- **WHEN** команда вызвана с `--list "Покупки"`
- **THEN** экспортируются только напоминания из списка «Покупки»

#### Scenario: Фильтр по нескольким спискам
- **WHEN** команда вызвана с `--list "Покупки" --list "Работа"`
- **THEN** экспортируются напоминания из обоих списков

#### Scenario: Фильтр без указания списка
- **WHEN** команда вызвана без `--list`
- **THEN** экспортируются напоминания из всех списков

### Requirement: Аргумент --completed (фильтр по статусу)
Аргумент `--completed` SHALL принимать `true` или `false`. При `true` SHALL экспортироваться только выполненные, при `false` — только невыполненные. Без аргумента SHALL экспортироваться все.

#### Scenario: Только выполненные
- **WHEN** команда вызвана с `--completed true`
- **THEN** экспортируются только напоминания с `isCompleted == true`

#### Scenario: Только невыполненные
- **WHEN** команда вызвана с `--completed false`
- **THEN** экспортируются только напоминания с `isCompleted == false`

#### Scenario: Без фильтра
- **WHEN** команда вызвана без `--completed`
- **THEN** экспортируются все напоминания независимо от статуса

### Requirement: Интеграция CLI с сервисом и экспортёром
Метод `run()` SHALL создавать сервис (`EventKitReminderService`), получать напоминания, применять фильтры и вызывать соответствующий экспортёр. При ошибке SHALL выводить сообщение в stderr и завершаться с ненулевым кодом.

#### Scenario: Успешный экспорт
- **WHEN** сервис возвращает напоминания
- **THEN** экспортёр создаёт файл, в stdout выводится сообщение об успехе, код выхода 0

#### Scenario: Ошибка доступа к Reminders
- **WHEN** сервис выбрасывает `accessDenied`
- **THEN** в stderr выводится понятное сообщение, код выхода 1

#### Scenario: Ошибка записи файла
- **WHEN** экспортёр выбрасывает ошибку
- **THEN** в stderr выводится сообщение с путём к файлу, код выхода 2
